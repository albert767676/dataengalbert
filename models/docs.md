# Витрины интернет-магазина

В проекте собраны аналитические таблицы интернет-магазина с помощью dbt и Greenplum.

Исходные данные хранятся в PostgreSQL. Сервис loader загружает их в Greenplum в схему raw, после чего dbt обрабатывает данные и создаёт витрины.

Модели разделены на три слоя:

- staging: подготовка исходных таблиц;
- intermediate: объединение данных и промежуточные расчёты;
- marts: итоговые таблицы для аналитики.

В проекте пять основных витрин:

- fct_orders: заказы, суммы и информация об оплатах;
- fct_order_items: товары внутри заказов, количество, цены и скидки;
- dim_customers: клиенты, количество покупок и общая выручка;
- dim_products: товары, бренды и категории;
- dim_dates: календарь для анализа заказов по датам.

Тестовые заказы не включены в итоговые таблицы фактов.

Для проверки данных используются стандартные тесты dbt и отдельные SQL-тесты на бизнес-логику.

В исходных данных есть заказ 113, по которому прошло два списания по 200 при сумме заказа 200. Для этой ситуации добавлен тест с уровнем severity: warn. Исходные данные не изменялись.
